# 競馬の歴史
競馬の歴史を一言でいうと、  
**馬の能力を競う行事が、軍馬育成と娯楽を経て、公営ギャンブルへ発展した歴史**です。  

### ① 古代～江戸時代
日本では古くから馬が重要な戦力でした。
```text
神事としての「競馬（くらべうま）」
武士の馬術訓練
流鏑馬（やぶさめ）
```
などが行われていました。  
ただし、現在のような楕円形コースを走る競馬ではありません。  

### ② 近代競馬の誕生（1860年代）
現在の競馬の原型は、横浜の外国人居留地で行われた西洋式競馬です。
```text
1860年ごろ 横浜で洋式競馬開催
1862年 日本初の洋式競馬場が誕生
1866年 横浜競馬場（根岸競馬場）が整備
```
ここが日本近代競馬の出発点とされています。

### ③ 競馬法と公認競馬（1900～1930年代）
日清戦争・日露戦争を経て、
```text
「強い軍馬を育てるには馬の改良が必要」
```
という考えから競馬が奨励されました。

その後、
```text
1905年 馬券発売が認められる
1923年 競馬法制定
各地の競馬倶楽部が設立
```
という流れになります。

### ④ 日本ダービー誕生（1932年）
競馬ファンなら有名な
```text
東京優駿（日本ダービー）
```
が1932年に創設されました。
現在でも最も権威あるレースの一つです。

### ⑤ 戦後の国営競馬
第二次世界大戦後、
```text
日本競馬会が解散
国営競馬へ移行
```
しました。

### ⑥ JRA誕生（1954年）
1954年、
```text
日本中央競馬会（JRA）
```
が設立されます。

この時から現在の中央競馬の仕組みが始まりました。   
主な競馬場は
```text
東京
中山
京都
阪神
中京
```
など現在とほぼ同じです。

### ⑦ 国際化（1980年代以降）
1981年、   
```text
ジャパンカップ
```
創設。
世界の強豪馬を日本へ招待するレースで、
日本競馬の国際化が大きく進みました。

### ⑧ 世界トップレベルへ
1990年代以降、
```text
オグリキャップ
ディープインパクト
オルフェーヴル
アーモンドアイ
イクイノックス
```
などの名馬が登場し、  
日本競馬は**世界最高水準の競馬賞金と競走レベル**を持つまでに成長しました。  

歴史の流れ（超要約）  
```text
神事・武士の競馬
    ↓
横浜で洋式競馬（1860年代）
    ↓
競馬法制定
    ↓
日本ダービー創設（1932）
    ↓
国営競馬
    ↓
JRA発足（1954）
    ↓
ジャパンカップ（1981）
    ↓
世界トップクラスの競馬大国へ
```

面白いのは、現在の競馬場25場のうち、  
東京・中山・京都・阪神などの中心競馬場のルーツは**100年以上前**までさかのぼることです。  

競馬場の位置データをGISで見ると、  
明治時代から続く競馬文化の痕跡が今でも残っています。

# 公営ギャンブル　とは
公営ギャンブルとは、  
国や地方自治体などの公共団体が法律に基づいて運営するギャンブルです。  

日本では賭博（ギャンブル）は原則禁止ですが、  
法律で特別に認められたものだけが公営ギャンブルとして実施されています。  

代表的なものは次の5種類です。
| 種類 | 主催 | 
| ---- | ---- | 
| 競馬  | JRA・地方自治体 | 
| 競輪 | 地方自治体 | 
| ボートレース（競艇） | 地方自治体 | 
| オートレース | 地方自治体 | 
| スポーツ振興くじ（toto） | 日本スポーツ振興センター | 

競馬なら、  
```text
馬券を購入
的中すると払戻金を受け取る
売上の一部は賞金や運営費になる
残りは自治体収入や社会還元に使われる
```
という仕組みです。

構造としては、
```text
利用者
 ↓
投票（馬券購入）
 ↓
売上
 ├─ 払戻金
 ├─ 運営費
 ├─ 賞金
 └─ 自治体収入
```
です。

例えば  
地方競馬や競輪、ボートレースでは、
収益が自治体の財源となり、  
公共サービスの原資として活用されることがあります。  

歴史的には、
```text
賭博は禁止
 ↓
財源確保のため例外的に認可
 ↓
公営競技として制度化
 ↓
現在の競馬・競輪・競艇・オートレース
```
という流れで発展しました。

面白い点として、  
競馬場は全国25場しかありませんが、  
競輪場は40場超、  
ボートレース場は24場あり、    
公営ギャンブルごとに施設の分布がかなり違います。  

GISで分析すると、  
競馬は広大な土地が必要なため都市周辺に点在し、  
競輪やボートレースは比較的設置しやすい傾向が見えてきます。  






# 競馬場の施設設備
競馬場は単にレースをする場所ではなく、  
「馬の生活・調教・競走・観客サービス」を支える巨大施設です。  

主な設備を整理すると、  
### ① コース
レースを行う場所です。
```text
芝コース
ダートコース
障害コース（一部競馬場）
直線走路
```
例：
```text
東京競馬場：芝・ダート・障害
中山競馬場：芝・ダート・障害
新潟競馬場：日本最長級の直線コース
```

### ② パドック
レース前に馬を周回させる場所です。
観客は
```text
馬体
歩き方
気配
発汗状況
```
などを確認します。

### ③ 厩舎（きゅうしゃ）
馬の住居です。  
設備例  
```text
馬房
飼料庫
洗い場
装蹄スペース
```
ただしJRAでは多くの競走馬は  
```text
美浦トレーニングセンター
栗東トレーニングセンター
```
に所属しており、開催時に競馬場へ輸送されます。  

### ④ 検量室
騎手や関係者の管理施設です。  
ここで  
```text
騎手の体重測定
装備確認
レース後の審議
```
などが行われます。  

### ⑤ 発走設備
レース開始のための設備です。  
```text
ゲート（発馬機）
スタート地点
判定装置
```

### ⑥ 写真判定設備
ゴール順を判定します。  
```text
高速カメラ
写真判定システム
着差測定装置
```
僅か数センチの差も判定できます。

### ⑦ 馬診療施設
競走馬専用の医療設備です。  
```text
診察室
レントゲン
超音波検査
救護馬運搬車
```
人間の病院に近い設備があります。  

### ⑧ 馬場管理設備
コースを維持する設備です。  
```text
芝刈り機
散水設備
排水設備
整地車両
```
競馬場では毎日のように馬場整備が行われます。  

### ⑨ 観客施設
一般来場者向けです。  
```text
スタンド
指定席
フードコート
ファミリーエリア
イベント広場
```
東京競馬場などは競馬以外の日でも公園のような規模です。  

### ⑩ 馬券発売設備
現在はネット投票が主流ですが、  
```text
発券機
払戻機
キャッシュレス端末
```
も設置されています。  

### ⑪ 放送・情報システム
競馬場全体を支えるIT設備です。  
```text
オッズ計算
馬券発売システム
映像中継
着順判定
大型ビジョン
```
近年は巨大なデータセンター並みのシステムで運用されています。

構造としては、  
```text
競馬場
├─ レース施設
│   ├─ コース
│   ├─ ゲート
│   └─ 写真判定
├─ 馬関連施設
│   ├─ パドック
│   ├─ 厩舎
│   └─ 診療施設
├─ 運営施設
│   ├─ 検量室
│   ├─ 審判室
│   └─ ITシステム
└─ 観客施設
    ├─ スタンド
    ├─ 飲食店
    └─ 馬券売場
```

GISで見ると競馬場は「スポーツ施設」というより、  
小さな町ひとつ分の機能を持った複合施設に近い存在です。  

東京競馬場や中山競馬場クラスになると、  
スタンド、厩舎地区、馬場、駐車場を含めて非常に広大な敷地になります。

# JRA とは
JRAとは、**日本中央競馬会（Japan Racing Association）**の略称です。  
中央競馬を運営する特殊法人で、**農林水産大臣の監督下**に置かれています。  
1954年9月16日に設立されました。  

簡単にいうと、  
```text
JRA = 日本の「中央競馬」を運営する組織
```
です。

主な役割は、
```text
中央競馬の開催
競馬場の運営
出馬表・オッズ・レース結果などの提供
馬券の発売・払戻し
競馬中継・ライブ配信
馬事・畜産振興など
```
JRAの中央競馬には、東京・中山・京都・阪神など全国10の競馬場があります。

また、前に出てきた地方競馬はJRAとは別の仕組みです。
```text
日本の競馬
├─ 中央競馬 → JRA
└─ 地方競馬 → 地方自治体など
```
この違いを押さえると、日本の競馬の構造がかなり分かりやすくなります。

# JRAと地方競馬の違いは？
簡潔にいうと、
**JRAは全国規模の「中央競馬」、地方競馬は各自治体が運営する「地方の競馬」**です。

項目	JRA（中央競馬）	地方競馬運営	日本中央競馬会（JRA）	都道府県・市町村など
競馬場数	10場	15場
主な開催日	土日中心	平日中心
コース	芝＋ダート	主にダート
賞金	高額	比較的低め
代表的競馬場	東京、中山、京都、阪神	大井、川崎、船橋、浦和など

イメージとしては、
```text
日本の競馬
├─ JRA（中央競馬）
│   ├─ 東京競馬場
│   ├─ 中山競馬場
│   ├─ 京都競馬場
│   └─ 阪神競馬場
│
└─ 地方競馬
    ├─ 大井競馬場
    ├─ 川崎競馬場
    ├─ 船橋競馬場
    └─ 高知競馬場
```
です。

競走馬で例えると、
```text
ディープインパクト
アーモンドアイ
イクイノックス
```
のような全国的なスターホースは主にJRAで活躍しました。

一方で地方競馬は、
```text
地域密着
平日開催
ナイター開催
```
が特徴です。

あなたのGISの視点だと、
```text
JRA競馬場：全国10か所の大規模拠点
地方競馬場：全国15か所の地域拠点
WINSやJ-PLACE：馬券販売ネットワーク
```
と見ると構造が分かりやすいです。

つまり、  
JRAは「全国チェーン本店」、地方競馬は「地域店舗」のような関係  
だとイメージすると理解しやすいですね。  

# 競馬場の配信システム
競馬場の配信システムは、単なる映像配信ではなく、  
```text
「レース映像・実況・オッズ・馬券発売・着順判定をリアルタイムに全国へ配信する巨大システム」  
```
です。  

構造としては、  
```text
競走馬
 ↓
競馬場
 ↓
映像・音声取得
 ↓
中央システム
 ↓
全国配信
 ├─ 競馬場
 ├─ WINS
 ├─ J-PLACE
 ├─ テレビ局
 ├─ インターネット
 └─ スマホアプリ
```

### 映像配信
競馬場には多数のカメラがあります。  
```text
スタート地点
向正面
第3・第4コーナー
ゴール前
パドック
ウイナーズサークル
```
などを撮影し、テレビ中継やネット配信へ送ります。  

### オッズ配信
馬券が購入されるたびに、  
```text
馬券購入
 ↓
中央サーバ
 ↓
オッズ再計算
 ↓
全国配信
```
が繰り返されます。  
そのためレース直前は秒単位でオッズが変化します。  

### 発売システム
JRA-VANや即PATなどを含め、  
```text
競馬場
WINS
インターネット投票
```
の購入情報を集約しています。  
大量アクセスが発生するため、高い可用性が求められます。  

### 着順判定システム
ゴール前では  
```text
高速カメラ
写真判定装置
着差測定装置
```
が使用されます。  
僅差の場合は写真判定画像が審議に利用されます。  

### データ配信
レースごとに  
```text
馬場状態
天候
発走時刻
出走表
オッズ
払戻金
着順
```
などのデータが**リアルタイム**で生成されます。
競馬サイトやアプリの表示は、このデータ配信を受けて更新されています。

### 障害対策
競馬は売上規模が非常に大きいため、  
```text
サーバ冗長化
回線二重化
バックアップセンター
```
などが整備されています。  

ITの観点で見ると、  
```text
銀行システム + 動画配信システム + リアルタイム集計システム
```
に近い性質があります。  

あなたがこれまで学んできた  
```text
DB
SQL
トランザクション
コネクション管理
パフォーマンスチューニング
```
の知識で見ると、  
競馬の配信システムは典型的な**大規模トランザクション処理システム（OLTP）**です。  

例えば  
「東京競馬場の第11レース締切直前に数万人が同時に馬券を購入しても、  
オッズ計算と発売処理を止めない」というのが重要な要件になります。  

# 住所付きCSV 
住所付きCSVを作るなら、  
まず確実に取得できる競馬場25施設から始めるのがおすすめです。  
JRA10場・地方15場の住所は公開されています。

なお、  
J-PLACEは約60施設あり、  
各施設の詳細住所は地方競馬側の発売所ページを個別に辿る必要があります。  

JRA公式には施設名一覧はありますが、  
住所一覧はまとまって掲載されていません。  

GIS用なら、
```text
競馬場25施設
WINS・エクセル35施設
J-PLACE約60施設
```
の約120施設すべてについて住所・緯度経度付きCSVを作成すると、  
国土数値情報のポイントデータと結合しやすくなります。  

- WINS全施設を住所付きで追加して
- J-PLACEの住所も調べて追加して
- CSVに緯度経度列も追加して
