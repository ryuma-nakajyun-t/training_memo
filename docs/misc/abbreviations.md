# 略語
### 必須
 | 略語 | 正式名称 | 意味 | 利用頻度 | 用途 | 
 | --- | --- | --- | --- | --- |
 | WIP | Work In Progress | 作業中 | ★★★★★ | 実装中・執筆中 | 
 | TODO | To Do | 今後対応 | ★★★★★ | 未実施タスク | 
 | TBD | To Be Determined | 未定 | ★★★★☆ | 内容未確定 | 
 | TBA | To Be Announced | 後日公開 | ★★★☆☆ | 仕様・日程未公開 | 
 | DRAFT | Draft | 下書き | ★★★★☆ | 未完成文書 | 
 | POC | Proof of Concept | 概念実証 | ★★★☆☆ | 検証用 | 
 | MVP | Minimum Viable Product | 最小実装版 | ★★★☆☆ | 初期版 | 
 | RFC | Request For Comments | 意見募集 | ★★★☆☆ | レビュー依頼 | 
 | N/A | Not Applicable | 対象外 | ★★★★☆ | 実施予定なし |
