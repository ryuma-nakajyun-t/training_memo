# softwareたちのショートカットキーをまとめてみた
```text
☣ 道具は使用して覚える。
```

- Windows
  - Navigation（移動）
  - Action（操作）
  - Editing（編集）
- ターミナル（PowerShell / Bash / WSL）
  - Navigation（移動）
  - Action（操作）
  - Editing（編集）
- VSCode
  - Navigation（移動）
  - Action（操作）
  - Editing（編集）
- Eclipse
  - 編集  
  - コード整形
  - 検索
  - デバッグ

## Windows
### Navigation（移動）
| 操作 | キー |
|------|------|
| タスクバーのアプリ起動 | Win + 数字キー |
| ウィンドウ切替 | Alt + Tab |
| 仮想デスクトップ | Win + Tab |
| Explorer起動 | Win + E |
| 実行ダイアログ | Win + R |
| ロック | Win + L |

### Action（操作）
| 操作 | キー |
|------|------|
| スクショ | Win + Shift + S |
| クリップボード履歴 | Win + V |
| 最小化したウィンドウを戻す | Win + Shift + M |
| 最大化 | Win + ↑ |
| 最小化 | Win + ↓ |
| 左右スナップ | Win + ← / → |
| ディスプレイ間移動 | Win + Shift + ← / → |
| スナップ幅の段階変更 | Win + Ctrl + ← / → |

### Editing（編集）
| 操作 | キー |
|------|------|
| タスクマネージャ | Ctrl + Shift + Esc |
| パスバーへ移動（Explorer/ブラウザ） | Ctrl + L |

## ターミナル（PowerShell / Bash / WSL）
### Navigation（移動）
| 操作 | キー |
|------|------|
| 画面クリア | Ctrl + L |
| 履歴検索 | Ctrl + R |
| 行頭へ | Ctrl + A |
| 行末へ | Ctrl + E |
| 行頭まで削除 | Ctrl + U |
| 行末まで削除 | Ctrl + K |

### Action（操作）
| 操作 | キー |
|------|------|
| 補完 | Tab |
| 新しいタブ | Ctrl + Shift + T |
| タブを閉じる | Ctrl + Shift + W |
| スクロール（Windows Terminal） | Ctrl + Shift + ↑↓ |

### Editing（編集）
| 操作 | キー |
|------|------|
| ペースト | Ctrl + Shift + V |
| コピー | Ctrl + Shift + C |
| 単語単位移動 | Ctrl + ← / → |

## VSCode
### Navigation（移動）
| 操作 | キー |
|------|------|
| ファイル移動 | Ctrl + P |
| シンボル移動（関数ジャンプ） | Ctrl + Shift + O |
| タブ移動 | Ctrl + Tab |
| 逆方向タブ移動 | Ctrl + Shift + Tab |
| ターミナル開閉 | Ctrl + ` |
| サイドバー開閉 | Ctrl + B |
| Explorerへ | Ctrl + Shift + E |
| 検索へ | Ctrl + Shift + F |

### Action（操作）
| 操作 | キー |
|------|------|
| 対応する括弧へジャンプ | Ctrl + Shift + \\ |
| 行の入れ替え | Alt + ↑↓ |
| 行の複製 | Shift + Alt + ↑↓ |
| コメント化 | Ctrl + / |
| 行削除 | Ctrl + Shift + K |

### Editing（編集）
| 操作 | キー |
|------|------|
| 次の一致を選択 | Ctrl + D |
| 全一致選択 | Ctrl + Shift + L |
| 単語単位選択 | Ctrl + Shift + → / ← |
| 単語削除 | Ctrl + Backspace |

優先的に覚える  
```text
Ctrl + Shift + F   フォーマット
Ctrl + Shift + O   import整理
Ctrl + Space       コード補完
Ctrl + 1           クイック修正
F3                 定義へジャンプ
Ctrl + Shift + T   クラス検索
Alt + Shift + R    リネーム
```
