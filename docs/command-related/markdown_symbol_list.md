# Markdownの主な記法
-  Markdownで使える主な記法をまとめます.

## 項目一覧
--- 
- マークダウン記法
- コードブロックの言語指定
- GitHub特有の便利記法
 
### マークダウン記法
---
| 分類 | 記法 | 用途 | 
| --- | --- | --- |  
| 見出し1 | # 見出し | 大見出し | 	
| 見出し2 | ## 見出し | 中見出し |  
| 見出し3 | ### 見出し | 小見出し |  
| 見出し4 | #### 見出し | 詳細見出し |  
| 段落 | 空行を入れる | 文章を区切る |  
| 改行 | 行末にスペース2個 | 強制改行 |  
| 太字 | **太字** | 強調 |  
| 斜体 | *斜体* | 強調 |  
| 太字＋斜体 | ***文字*** | 強い強調 |  
| 打消し線 | ~~文字~~ | 削除・非推奨 |  
| 引用 | > 引用 | 引用文 |  
| ネスト引用 | >> 引用 | 二重引用 |  
| 箇条書き | - 項目 | リスト |  
| 箇条書き | * 項目 | リスト |  
| 箇条書き | + 項目 | リスト |  
| 番号付き | 1. 項目 | 順序付き |  
| チェックボックス | - [ ] | TODO |  
| 完了チェック | - [x] | 完了 |  
| インラインコード | `code` | コード強調 |  
| コードブロック | ``` | 複数行コード |  
| 水平線 | --- | 区切り線 |  
| 水平線 | *** | 区切り線 |  
| リンク | URL | URLリンク |  
| 自動リンク | <https://...> | URL表示 |  
| 画像 | image.png | 画像表示 |  
| テーブル | ` | 列1 | 列2 | ` | 表
| エスケープ | \# | 記号を文字表示 |  
| HTML埋込 | <br> | HTML併用 |  
| HTML埋込 | <details> | 折りたたみ |

### GitHub特有の便利記法
---
| 記法 | 用途 |
| --- | --- |  
| @ユーザー名 | メンション | 
| #123 | Issue参照 | 
| GH-123 | Issue番号 | 
| :smile: | 絵文字 | 
| - [ ] | タスク管理 | 
| - [x] | タスク完了 | 
| <!-- コメント --> | コメント（非表示） |
