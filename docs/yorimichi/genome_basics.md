ゲノム（genome）とは、生物が持つ遺伝情報の全体のことです。

簡単にいうと、
- 遺伝子 = 設計書の一部
- ゲノム = 設計書の全部
という関係です。

例えば人間の場合、
```text
細胞の中にDNAがある  
DNAには約2万個の遺伝子が含まれる  
その遺伝子だけでなく、遺伝子以外の領域も含めたDNA全体を「ゲノム」と呼ぶ  
```
というイメージです。

システム開発に
例えると

あなたが学習しているITの世界でたとえるなら、  
- 遺伝子 = 個々のJavaクラスや設定ファイル
- ゲノム = Gitリポジトリ全体
に近いです。

1つの機能だけを見るのが遺伝子、 システム全体のコードや設定を含めて見るのがゲノムです。

ゲノム解析とは？  
ゲノム解析では、  
- 病気になりやすい体質
- 薬が効きやすいか
- 祖先のルーツ
- 生物同士の進化の関係
などを調べます。

有名なのが「ヒトゲノム計画」で、人類のDNA配列の全体像を解読する大規模プロジェクトでした。

一言でいうと、  
ゲノム = 生物を作るためのDNAの全設計図  
です。
